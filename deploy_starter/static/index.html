📖 使用指南

                
            

            

                
                
                

                    
🚀 首次使用

                    

                        第一步：点击右上角 ⚙ 进入设置
                    

                    
    
                        
  • LLM 设置 — 配置 API Key 和模型（支持 OpenAI 兼容接口）
    • 
                        
  • 您的相关信息 — 填写同事可能如何称呼您（名字、职位等），帮助 AI 更准确判断邮件相关性
    • 
                        
  • 同步设置 — 可调整自动同步间隔、扫描邮件数量等
    • 
                    

                    

                        第二步：同步邮箱
                    

                    
    
                        
  • 在顶部输入您的邮箱地址和密码/授权码
    • 
                        
  • 选择邮箱服务商（或自定义 POP3 服务器）
    • 
                        
  • 点击「同步邮箱」按钮，系统会自动分析邮件、提取待办事项
    • 
                    

                

                
                

                
                
                

                    
✨ 功能介绍

                    
    
                        
  • 智能提取待办 — AI 分析邮件内容，识别需要您处理的事项
    • 
                        
  • 截止日期识别 — 自动提取邮件中提到的截止时间
    • 
                        
  • 待办列表 — 按截止日期排序，区分有/无截止时间
    • 
                        
  • 日历视图 — 在日历上直观查看待办分布
    • 
                        
  • 智能转发 — AI理解自然语言规则，自动转发匹配邮件给指定收件人
    • 
                        
  • 聊天助手 — 用自然语言查询待办（如"今天有什么事"、"哪些快到期了"）
    • 
                        
  • 自动同步 — 定时检查新邮件，自动提取待办
    • 
                    

                

                
                

                
                
                

                    
🤖 智能分析说明

                    

                        系统会智能判断邮件中提到的事件是否需要您处理：
                    

                    
    
                        
  • 设置"您的称呼"可提高准确率 — 如您的名字、职位、部门等
    • 
                    

                

                
                

                
                
                

                    
📤 智能转发说明

                    

                        系统支持基于AI的智能邮件转发，自动将满足条件的邮件转发给指定收件人：
                    

                    
    
                        
  • 配置SMTP发送邮箱 — 在设置的"SMTP 发送设置"中配置
    • 
                        
  • 创建转发规则 — 在"转发规则"标签页用自然语言描述转发条件
    • 
                        
  • AI自动判断 — 同步邮件时，AI会根据规则自动判断是否转发
    • 
                        
  • 支持多规则多收件人 — 一封邮件可匹配多条规则，每条规则可有多个收件人
    •
