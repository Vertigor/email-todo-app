# 邮箱待办助手

一个帮你自动整理邮件待办事项的桌面小工具。它能连接你的邮箱，读取最近的邮件，然后用 AI 帮你分析出哪些邮件里有你需要做的事情，自动生成待办清单。

- **自动读取邮箱**：连接邮箱，获取最近的邮件
- **AI 智能分析**：自动分析邮件内容，提取出你需要做的事
- **待办清单**：生成待办事项列表，可以标记完成
- **日历视图**：在日历上直观查看各项待办的截止日期
- **AI 对话助手**：可以和 AI 聊天，询问待办相关问题
- **定时自动同步**：启动后每分钟自动检查一次新邮件

---

## 使用说明

### 1. 打开应用

双击运行 `EmailTodoApp.exe` 即可，会自动弹出应用界面。

### 2. 首次使用：配置 AI 服务

第一次使用时，需要先配置 AI 服务才能分析邮件：

1. 点击界面右上角的 **⚙ 设置** 按钮
2. 在"LLM 设置"中填入 **API Key** 和**模型地址**
3. 保存设置

如果不确定怎么填，请联系管理员获取。这个只需要配置一次，之后会自动记住。

### 3. 配置邮箱

在界面顶部：

1. 输入你的**邮箱地址**
2. 输入你的**邮箱密码或授权码**
3. 选择对应的**邮箱类型**；如果不在列表中，选择"自定义"并填入 POP3 服务器和端口
4. 如果想下次自动填入密码，可以勾选**"记住密码"**

### 4. 同步邮件

点击 **"同步邮箱"** 按钮，程序会：

1. 连接你的邮箱，下载最近的邮件
2. 用 AI 分析邮件内容
3. 自动提取出待办事项，显示在下方列表中

第一次同步可能需要一些时间，取决于邮箱中的邮件数量。

### 5. 管理待办

- **查看待办**：在"待办列表"页面查看所有待办事项
- **标记完成**：完成某件事后，点击对应待办将其标记为已完成
- **日历视图**：切换到"日历"页面，可以按日期查看待办的截止时间
- **AI 对话**：切换到"聊天"页面，可以和 AI 助手对话

### 6. 自动同步

应用启动后会**每分钟自动检查一次**新邮件。如果有新邮件，会自动分析并更新待办列表，你不需要手动操作。

## 常见问题

### 邮箱连接失败

- 检查邮箱地址和密码是否输入正确
- 确认所在网络可以访问对应邮箱服务器

### AI 分析失败

- 点击右上角 ⚙ 设置，检查 API Key 和模型地址是否填写正确
- 确认所在网络可以访问 LLM 接口

---

## 注意事项

- 如果勾选了"记住密码"，邮箱密码会加密保存在本地
- 所有待办数据保存在本地，不会上传到任何外部服务器

# 以下内容面向开发者

---

## 开发环境搭建

需要 Python 3.9 或更高版本。

```
cd D:\codes\mcp_server_with_chat
pip install -r requirements.txt
```

## 以开发模式运行

```
python -m deploy_starter.launcher
```

启动后会自动打开桌面窗口。如果没有安装 PyQt5，也可以在浏览器中访问：

```
http://localhost:18080/static/index.html
```

## 打包 exe

```
pyinstaller build_exe.spec --noconfirm
```

打包完成后，`dist/EmailTodoApp.exe` 即为可分发的独立程序。
